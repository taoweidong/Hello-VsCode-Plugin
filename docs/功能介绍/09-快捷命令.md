# 09 · 快捷命令（Quick Commands）

> v3.5.0 新增（设计方案见[需求与优化方案 16](../需求与优化方案/16-快捷命令设计方案.md)）：
> 把常用终端命令收藏成"一键执行"的快捷命令——支持从终端选区一键收藏、手动新增、
> 别名、分组管理，侧边栏按「分组 → 命令」两级树展示，**单击即在终端执行**。

## 它解决什么问题

- 部署、清缓存、跑脚本这类高频命令，每次都要翻历史或重新敲；
- 命令太长记不住，别名（如 `push` = `git push origin main`）一劳永逸；
- 任务管理器（TaskExplorer）只认 `.vscode/tasks.json` 里的任务——快捷命令补上
  **裸 shell 命令**这块（两者正交，见[07-TaskExplorer任务管理器](07-TaskExplorer任务管理器.md)）。

## 入口一览

| 入口              | 操作                                                               |
| ----------------- | ------------------------------------------------------------------ |
| 命令面板          | `快捷命令: 新增快捷命令` / `快速执行快捷命令` / `收藏终端选中命令` |
| 视图标题栏        | ➕ 新增 / ▶ 快速执行 / 🗂 新建分组                                  |
| 终端右键          | 收藏终端选中命令                                                   |
| 树节点单击        | **立即在终端执行该命令**                                           |
| 树节点右键 / 悬停 | 执行 ▶ / 重命名 / 删除（inline）/ 编辑 / 移动到分组 / 复制 / 删除  |

## 三种收藏方式

1. **收藏终端选中的命令**：在终端里选中（或光标停在）刚执行过的命令 →
   命令面板「收藏终端选中命令」→ 起别名 → 选分组。实现走剪贴板桥接
   （内部命令复制选区 → 读剪贴板 → 恢复原内容），任何失败自动降级为粘贴输入框。
2. **手动新增**：命令面板「新增快捷命令」→ 输入命令（支持多行）→ 别名（默认取命令首词）→ 选分组。
3. **分组**：命令必属一个分组（默认「未分组」，固定显示在末位）；分组可新建/重命名/删除，
   删除分组时组内命令回落未分组（有模态确认）。

## 执行语义

- 单击/回车 = 在名为 **QuickCommand** 的专用终端里原样执行（`sendText`）；
  终端被手动关闭后下次执行自动重建；设置 `extStarter.quickCommandReuseTerminal: false`
  可改为每次新建终端；
- 命令文本**原样发送**，不做任何转义改写（含 `cd` 的组合命令照常工作）；
- 每次执行回写使用次数与最近使用时间（tooltip 可见）；
- `快速执行快捷命令` QuickPick 支持按**别名或命令全文**模糊搜索，分组分隔显示，
  回车即执行。

## 存储与边界

- 数据落 `.vscode/quick-commands.json`（信封 + 原子写 + 损坏自动备份，已 gitignore，
  跟着工作区走、可直接提交进仓库共享给团队）；未打开工作区时回退 globalState；
- 上限 200 条命令 / 50 个分组；同一命令文本去重（重复收藏仅提示）；
- 与收藏夹（收藏文件/文件夹路径）和任务收藏（收藏 tasks.json 任务）正交，互不相混。
