# 10 · 代码书签

> 行级书签：给关键代码行「钉图钉」，之后在书签间快速跳转——大项目里不再靠
> 反复搜索找位置。设计方案见[需求与优化方案 14](../需求与优化方案/14-代码书签设计方案.md)。

## 是什么

「书签」是**代码行级**的收藏：在任意文件的关键行打上书签，侧边栏树按文件分组展示，
三种方式快速跳回。与「收藏夹」（收藏文件/文件夹**路径**，见 [08](08-收藏夹.md)）
正交互补——一个管「去哪个文件」，一个管「看哪一行」。

## 快捷键

| 快捷键（Win/Linux） | mac         | 作用                                      |
| ------------------- | ----------- | ----------------------------------------- |
| `Ctrl+Alt+K`        | `Cmd+Alt+K` | 当前光标行打书签 / 再按一次取消（toggle） |
| `Ctrl+Alt+L`        | `Cmd+Alt+L` | 跳到下一个书签（跨文件循环）              |
| `Ctrl+Alt+J`        | `Cmd+Alt+J` | 跳到上一个书签（跨文件循环）              |

> 与开源 Bookmarks 插件的原版默认键一致——两个都装的话会冲突，可在
> 键盘快捷方式设置里重绑。Windows 部分键盘布局 `Ctrl+Alt` 即 AltGr，可能误触发。

## 入口与操作

- **打/取消书签**：编辑器里把光标放到目标行 → `Ctrl+Alt+K`；或编辑器右键 →
  「切换书签」；命令面板搜「切换书签」。成功有提示「已添加书签（第 N 行）」；
- **侧边栏树**（第 8 视图「书签」）：按文件分组 → 书签条目（行文本快照 + `L行号`），
  **单击任意条目直接跳到那一行**；单击文件分组跳到该文件第一条书签；条目悬停有
  删除按钮，右键可移除；视图标题栏有「快速打开书签 ⋮」「清空全部书签」「打开数据文件」；
- **QuickPick 快速跳转**：命令面板「快速打开书签」→ 列出全部书签（`文件:行号` +
  行文本），回车即跳；
- **循环跳转**：`Ctrl+Alt+L` / `Ctrl+Alt+J` 按「文件 + 行号」顺序在所有书签间循环，
  跨文件自动切换，尾首回绕——顺着看代码时像下一站/上一站。

## 相关设置

无（本功能无配置项；快捷键可在 VSCode 键盘快捷方式中重绑）。

## 数据落点

- 工作区：`.vscode/bookmarks.json`（信封 + 原子写 + 损坏自动备份 `.bak`；已 gitignore）；
- 未打开工作区：globalStorage 目录下的明文 `bookmarks.json`——与收藏夹一样，
  **手动拷贝该文件即可备份/迁移**（见 [08 · 收藏夹「备份与迁移」](08-收藏夹.md)）；
- 上限 500 条，超出自动丢最旧；只支持本地文件（`file:` 协议），
  untitled / 远程文档打点会提示「仅支持本地文件」。

## 常见问题

- **跳转位置不对 / 行号越界**：文件在打点后被编辑，行号漂移了——这是 v1 简单版
  的已知口径（只存行号、不做编辑追踪）；越界时自动钳制到文件末尾并提示，
  重新 `Ctrl+Alt+K` 打一次即可；
- **条目里的行文本和实际代码对不上**：条目显示的是打点时的文本快照（仅用于辨认），
  跳转以行号为准；
- **键位和 Bookmarks 插件冲突**：二者键位一致（有意对齐），重绑一边即可。
