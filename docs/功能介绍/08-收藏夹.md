# 08 · 收藏夹

> 「收藏夹」视图：把**任意文件 / 文件夹的路径**存成带别名的收藏——侧边栏一点直达，
> 配 QuickPick 快速打开。与「任务管理器」的任务收藏（`addTaskToFavorites`，收藏
> tasks.json 任务）正交。设计方案见
> [需求与优化方案 13](../需求与优化方案/13-收藏夹设计方案.md)。

## 如何使用

1. **添加收藏**（三处入口）：
   - 资源管理器右键文件或文件夹 → 「添加到收藏夹」（支持多选批量）；
   - 编辑器右键 → 「添加到收藏夹」（当前文件）；
   - 编辑器标题栏 ➕ 按钮（当前文件）；
2. **别名**：单个添加时弹输入框（默认文件名，留空即用文件名）；批量添加直接用
   文件名；之后随时右键条目 → 「重命名收藏别名」；
3. **单击直达**：文件 → 在编辑器打开；文件夹 → 在资源管理器中定位（reveal）；
4. **快速打开**：`Ctrl+Shift+P` → 「快速打开收藏」（或收藏夹视图标题栏 ⭐）→
   输入别名过滤 → 回车直达；
5. **管理**：条目右键 → 在资源管理器中显示 / 复制收藏路径（解析后的绝对路径）/
   重命名 / 移除；悬停条目可直接点 ✕ 移除（移除无需确认，重新添加即可）。

## 数据与规则

- 数据文件：工作区 `.vscode/favorites.json`（原子写 + 损坏自动备份 `.bak`；
  已 gitignore）；未打开工作区时落 globalStorage 目录下的明文 `favorites.json`
  （v3.6 起，同样可手动拷贝迁移）；
- 工作区内的收藏存**相对路径**（仓库移动 / 改名后仍可解析），工作区外存绝对路径；
  打开时按工作区文件夹逐个解析，目标不存在时给出错误提示；
- 上限 200 条，超出自动丢最旧；同一目标（解析后同路径）不会重复入列；
- 列表按收藏时间倒序（最新在最上）。

## 常见问题

- **点击条目报错「文件不存在」**：目标已被移动 / 删除——移除该条后重新收藏新路径；
- **多根工作区下解析到别的文件夹**：同名相对路径按先命中者解析（v1 已知限制，
  见设计方案 §4）；
- **想拖拽排序？** v1 未做（列表为最新优先），需求记录在设计方案 §2 非目标。

## 备份与迁移（v3.6）

收藏数据在所有场景下都是**可手动拷贝的明文 JSON 文件**——迁移 = 拷文件，无需导入导出：

| 场景         | 数据文件                              | 迁移方式                     |
| ------------ | ------------------------------------- | ---------------------------- |
| 有工作区     | `.vscode/favorites.json`              | 拷到目标机器同仓库同位置即可 |
| 未打开工作区 | globalStorage 目录下 `favorites.json` | 拷到目标机器同目录同名文件   |

- globalStorage 真实路径：Windows 为
  `%APPDATA%\Code\User\globalStorage\your-publisher.hello-vscode-plugin\`；
  收藏夹视图标题栏「打开数据文件」按钮可一键定位该文件（命令面板搜「打开收藏数据文件」）；
- 升级到 v3.6 前（旧版）在无工作区攒下的收藏：插件会在激活时**自动迁移**到上述
  明文文件（一次性、幂等，迁移成功才清理旧数据，失败保留旧数据并如实提示）；
- 代码行书签（[10 · 代码书签](10-代码书签.md)）的 `.vscode/bookmarks.json` 同口径。
