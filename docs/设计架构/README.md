1. 先读 [01-总体架构](01-总体架构.md)——记住两条边界规则与一条数据流；

3. 写面板/页面前过一眼 [03-关键流程与协议时序](03-关键流程与协议时序.md)——
   提交生命周期与消息顺序的「为什么」都在图里；
