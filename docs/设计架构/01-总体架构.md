# 01 · 总体架构

> 系统怎么组织：双进程拓扑、目录职责、边界规则、数据流、页面加载链与构建管线。
> 目录逐文件说明以 [开发指南 00 · 架构与目录](../开发指南/00-架构与目录.md) 为准，
> 本篇给全局视图与跨层链路。

## 1. 双进程拓扑

VSCode 扩展天然是两个隔离的 JS 上下文，本项目全部设计围绕这条物理边界展开：

```text
┌─ 扩展宿主进程（Node.js）────────────────┐      ┌─ Webview 进程（浏览器沙箱）─┐
│ src/extension/**                        │      │ src/webview/**              │
│                                         │      │                             │
│  index.ts 激活入口                      │      │  apps/<page>/main.ts 入口   │
│    ├─ commands/      命令分组           │      │    └─ App.vue 页面（Vue 3） │
│    ├─ features/      领域功能           │ post │  ui/        12 组件+令牌    │
│    ├─ providers/     树视图             │ ───► │  components/ SchemaForm     │
│    ├─ tasks/         启动任务框架       │ mess │  composables/ 组合式函数    │
│    └─ services/      存储/迁移/错误     │ age  │  host/      面板控制器※    │
│                                         │ ◄─── │                             │
│  vs code API / Node 内置                │      │  无 vscode、无 Node（CSP）  │
└─────────────────────────────────────────┘      └─────────────────────────────┘
                    ▲      唯一跨侧契约：src/webview/protocol.ts        ▲
                    └──────── 纯类型 + 运行时守卫（零依赖）─────────────┘

※ host/ 目录随扩展宿主编译（import vscode），但只服务页面外壳（HTML/CSP/资源解析）。
```

| 目录                         | 职责                                                                               |

| `src/extension/commands/`    | 命令按场景分组（page / draft / copy / taskExplorer / favorites / quickCommands）   |
| `src/extension/features/`    | 领域功能（init / taskManager / taskExplorer / drafts / favorites / quickCommands） |
| `src/extension/tasks/`       | 启动任务框架（探针/任务注册表 + 调度器）                                           |
| `src/extension/services/`    | 原子写 / 旧键迁移 / 错误类型                                                       |
| `src/webview/pages.ts`       | ★ 页面注册表（唯一扩展点）                                                         |
| `src/webview/protocol.ts`    | ★ 唯一跨侧契约（类型 + 守卫）                                                      |

| `src/webview/ui/`            | 设计系统（令牌 + 12 组件）                                                         |

| `scripts/`                   | 构建（build-extension）与门禁（gate + checks/）                                    |
| `src/test/`、`tests/e2e/`    | 单测（vitest 桩）/ 宿主集成 / Playwright e2e                                       |

## 3. 边界规则（写进门禁）

1. `src/extension/**` 只 import `vscode`，不 import Vue / Webview 侧代码；
2. `src/webview/**` 不 import `vscode`，只经 `postMessage` 与宿主通信；
3. 唯一跨侧契约 = `src/webview/protocol.ts`（联合类型 + 运行时守卫，
   两侧收发前必须过守卫，未知消息只记日志）；
4. Webview 样式红线（门禁强制）：颜色只用语义令牌、尺寸全走 `var(--ui-*)`、
   禁 `v-html` / `innerHTML` / 模板静态 style / 白名单外 import、
   产物 CSS 禁站点根绝对 `url(/…)`。

## 4. 数据流（典型链路，单向）

**任务管理（CRUD 请求-应答 + 提交生命周期）**：

```text
页面 taskListRequest → 面板 lastQuery → TaskApiClient（Stub 内存表 | Http fetch）
    → taskList 应答渲染（服务端分页语义：服务侧过滤 + createdAt 倒序 + slice）
页面 submit → api.create/update → submitAck 关框；失败 error（field 定位控件）
```

关键取舍：`taskList` 应答只负责数据刷新，**关框只认 `submitAck`**——否则轮询应答
先落时会误关弹框并伪造「已保存」（v3.3.0 修复的 P1，见 CHANGELOG）。

## 5. Webview 页面加载链

```text
pages.ts 登记 → vite rollupOptions.input 自动纳入 → 构建 .vite/manifest.json
  → assetResolver 反查入口 chunk + 递归收集 import 链 CSS
  → webviewHtml 拼 HTML（nonce CSP：default-src 'none' / base-uri 'none' / 无 unsafe-*）
  → WebviewController.createOrShow 单例 + dirty 守卫 + serializer 窗口重载恢复
```

两条事故防线沉淀在链路上：`base: './'`（CSS 相对 `url()`，否则 codicon 字体 404
全图标空白）与 `retainContextWhenHidden: false`（页面状态经 `getState/setState`
自行持久化，内存零常驻）。

## 6. 构建与产物管线

```text
tsx scripts/build-extension.ts --production   # 宿主 esbuild → dist/extension.js（≤150KB 预算）
npx vite build                                # Webview → dist/webview（manifest + hash 文件名，
                                              #   单 chunk ≤100KB、runtime-only 预编译、base './'）
npm run package:vsix                          # vsce 打包 → release/*.vsix（逐条目 CRC 校验）
```

打包黑白名单由门禁第 ⑨ 步校验：源码/测试/文档/coverage 不进包；
扩展宿主运行时零第三方依赖（v4.0.0 移除 serialport）。
完整门禁 10 步见 [开发指南 08 · 测试门禁与打包](../开发指南/08-测试门禁与打包.md)。

## 7. 横切机制

| 机制     | 落点                                                                    | 要点                                                                                                                    |
| -------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 错误处理 | `src/extension/services/errors.ts`                                      | 可诊断错误信息（带 method/path 上下文）                                                                                 |
| i18n     | `package.nls.json` / `package.nls.zh-cn.json`                           | manifest 文案 `%key%` 占位符，英文默认                                                                                  |
| 存储     | `services/stores/`（atomicWrite / jsonEnvelopeStore / queuedFileStore） | 工作区 JSON 原子写；无工作区回退 globalStorage 明文 JSON（收藏/快捷命令）                                               |
| 凭据     | VSCode SecretStorage                                                    | 密码唯一存放处，加载守卫剔除 `*password*` 键                                                                            |
| 遗留数据 | `src/extension/services/legacyFeatureCleanup.ts`                        | 下线功能（串口 v4.0.0 / 书签 v5.0.0）遗留数据激活时一次性清理；收藏/快捷命令 Memento → globalStorage 一次性迁移（幂等） |
