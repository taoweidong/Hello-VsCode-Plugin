## 2. 演进决策（v2.x → v3.x 落地，权威出处=代码 + CHANGELOG）

| 决策                                                      | 动机 / 教训                                                     | 锚点                                                  |
| --------------------------------------------------------- | --------------------------------------------------------------- | ----------------------------------------------------- |
| Vite `base: './'`（资源相对引用）                         | 站点根绝对 `url(/…)` 在 webview 域必 404——v0.7.0 全图标空白事故 | `vite.config.ts`；门禁红线扫 dist 产物                |
| 页面 `retainContextWhenHidden: false`                     | 内存零常驻；状态经 `getState/setState` 自持久化                 | `src/webview/pages.ts`                                |
| 样式尺寸令牌强制（R-U-4）                                 | `px` 字面量散落导致设计系统无法统一调整；门禁升级为逐声明校验   | `scripts/checks/style.ts` 规则 4                      |
| 浏览器模态 `confirm/alert/prompt` 禁用（v3.3.0 P0）       | webview 沙箱无 allow-modals，模态恒被忽略——删除/重置静默失效    | `useTwoStepConfirm` 两段式布防；门禁规则 8            |
| 提交生命周期 `submitAck` 关框、`taskList` 只刷数据        | 轮询应答先落会误关弹框并伪造「已保存」（v3.3.0 P1）             | `src/webview/apps/taskManager/App.vue`                |
| 任务管理 Stub/Http 双实现工厂                             | 同一协议下打桩与真实接口零改动切换（`createTaskApiClient`）     | `src/extension/features/taskManager/taskApiClient.ts` |
| 任务树形分组 maxLevel 默认 5 / 上限 15（v3.1.0）          | 短名按分隔符重拼，多层虚拟文件夹更贴近 vscode-taskexplorer 习惯 | `src/extension/features/taskExplorer/`                |
| vsix 逐条目 CRC 校验（v2.3.0 教训）                       | 拦截打包产物静默损坏                                            | `scripts/package-vsix.ts`                             |
| 门禁第⑩步 Webview E2E 可选（`--with-e2e`）                | 依赖真实浏览器，默认不阻塞日常门禁；CI 单独跑                   | `scripts/gate.ts`                                     |
| 扩展 ID 前缀 `extStarter.*`、项目更名（v1.0/v3.0 破坏性） | 模板收敛与品牌化；旧设置/数据激活时自动迁移                     | `src/extension/services/legacyMigration.ts`           |
