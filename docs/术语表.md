## 架构与边界

| 术语             | 定义                                                                  | 锚点 / 详解                              |
| ---------------- | --------------------------------------------------------------------- | ---------------------------------------- |
| 扩展宿主（进程） | 运行插件代码的 Node.js 进程，`src/extension/**`，只 import `vscode`   | [开发指南 00](开发指南/00-架构与目录.md) |
| Webview（页面）  | VSCode 内嵌浏览器沙箱，`src/webview/**`，禁止 import vscode           | 同上                                     |
| 唯一跨侧契约     | `protocol.ts`：宿主 ↔ 页面消息的联合类型 + 运行时守卫，两侧唯一通道   | `src/webview/protocol.ts`                |

| 双进程边界       | 宿主与页面两套 JS 上下文，一切设计围绕此物理隔离展开                  | [设计架构 01](设计架构/01-总体架构.md)   |

| 页面状态自持久化   | `retainContextWhenHidden` 恒 false；页面经 `getState/setState` 自存草稿                     | `src/webview/pages.ts`                         |

## 设计系统与门禁

| 术语               | 定义                                                                                               | 锚点 / 详解                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| 语义令牌           | `--ui-*`：组件唯一允许消费的颜色/尺寸来源，映射 `--vscode-*` 主题变量                              | `src/webview/ui/tokens.css`                                     |
| 令牌登记           | 新几何/颜色规格必须先登记进 tokens.css 再使用（样式门禁强制）                                      | 同上；[04 §9.4](需求与优化方案/04-VSCode原生设计系统.md)        |
| 样式门禁           | `scripts/checks/style.ts`：禁硬编码色 / 尺寸必须 var(--ui-*) / 禁 v-html / 静态 style / 浏览器模态 | 同上                                                            |
| 组件画廊           | `gallery` 页面：设计系统活验收基准，「抄它」的起点                                                 | `src/webview/apps/gallery/`                                     |
| 清单 ↔ 常量 ↔ 注册 | 命令/视图 ID 三方闭合：package.json ↔ constants.ts ↔ register 调用，门禁第⑥步静态校验              | `scripts/checks/manifest.ts`                                    |
| 质量门禁（gate）   | `npm run gate`：10 步 fail-fast（lint→类型→构建×2→测试编译→一致性→单测→集成→打包预算→e2e 可选）    | `scripts/gate.ts`；[开发指南 08](开发指南/08-测试门禁与打包.md) |
| `--fast`           | 跳过第⑧步宿主集成的日常模式                                                                        | 同上                                                            |
| `--with-e2e`       | 追加第⑩步 Playwright e2e（默认不进门禁，CI 单独跑）                                                | 同上                                                            |
| bundle 预算        | 宿主 ≤150KB / 单 chunk ≤100KB / vsix ≤20MB，超限门禁红                                             | `scripts/gate.ts`                                               |
| vsce 黑白名单      | vsix 内容校验：源码/测试/文档不进包，serialport 运行时必须在                                       | 同上                                                            |
| vscode 桩          | 单测里替换 `vscode` 模块的测试桩（只增不减）                                                       | `src/test/unit/stubs/vscode.ts`                                 |
| e2e harness        | `tests/e2e/server.mjs`：静态产物走 `/webview/**` 前缀模拟宿主资源域                                | `tests/e2e/server.mjs`                                          |
