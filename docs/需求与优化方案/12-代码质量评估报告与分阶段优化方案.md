## 5. 分阶段优化方案

> 原则：每阶段可独立验证（全量单测绿 + lint + 类型检查）；先写复现测试（红）再修复（绿）；
> 阶段内各项互相独立、可单独回滚；不做大规模结构重构。

### 阶段 0 · 基线固化与统计面扩容

- **目标**：覆盖率统计面扩至全部可测模块，让后续每一步的「行为不变」都有数字背书；补齐各文件缺口测试后阈值按实测校准。
- **涉及文件**：`vitest.config.ts`（include + thresholds）。
- **验收标准**：全量单测绿；统计面覆盖 §4 列出的全部模块；阈值不低于实测值减 1pt 余量。
- **回滚边界**：仅改测试配置，`git checkout vitest.config.ts` 即回原状，零生产代码风险。

### 阶段 1 · P1 缺陷修复（测试先行）

- **1a P1-1 双写通道**：面板侧 `saveServer`/`deleteServer` 改为「写前从 store 重读」作为真值源（对齐 draftBoxService 契约），操作成功后经 `pushServers` 统一通道刷新缓存与页面；控制器 `deleteServer` 复用面板同一路径，消除两份删除逻辑。
- **1b P1-2 自动登录代际守卫**：`maybeAutoLogin` 记录发起时的连接目标与代数，每次 `send` 前校验 `link.connectedServerId()` 仍是目标且仍 connected，否则静默终止本次登录序列。
- **涉及文件**：`serialConsolePanel.ts`、`serialConsoleController.ts`、对应 spec。
- **验收标准**：先落地两条复现测试（树删后面板保存不复活；连接切换后旧凭据不写入新端口），修复后全绿；现有 512 用例零回归。
- **回滚边界**：两项独立改动，各自可 revert；不改动协议与存储格式。

### 阶段 2 · P2 宿主侧修复

- **2a** `serialLinkService` 引入 `StringDecoder` 按字节缓冲解码（配跨 chunk 中文用例）。
- **2b** `initService` 超时后等待实际步骤落定再继续下一步（保持互斥语义）；`initSteps` envSnapshot 改用 `writeJsonAtomic`。
- **2c** `serialConsolePanel` SecretStorage 操作 try/catch + 错误经协议 error 下发；`void` 化 Promise 补 `.catch` 记日志。
- **2d** `environmentTask` 探针并行化（`Promise.all`，探针内候选命令保持串行回退语义不变；结果顺序与注册表一致）。
- **涉及文件**：`serialLinkService.ts`、`initService.ts`、`initSteps.ts`、`serialConsolePanel.ts`、`environmentTask.ts` + 各 spec。
- **验收标准**：每项配行为级测试（含异常分支）；全量单测绿；探针耗时从串行最坏 48s 降至单探针最坏 6s。
- **回滚边界**：每项独立可 revert；2d 不改变结果内容与顺序，仅改时序。

### 阶段 3 · P2 前端侧修复

- **3a** CommandInput：↓ 仅在已进入历史遍历时生效；进入遍历前保存草稿，↓ 回到 -1 时恢复草稿而非清空。
- **3b** buildConsole 主提交按钮改走 SchemaForm `validate()`，空必填字段本地拦截并聚焦（对齐 ServerForm 行为）。
- **3c** Esc 取消确认：编辑态（editingId 存在）时 `confirm()` 二次确认后再 reset，新增态保持直接 reset。
- **3d** `useConsolePage` init.extra 元素级守卫（`isSerialServerWire`/`isCommandHistoryWire` 过滤）。
- **3e** 密码掩码：formSchema 新增 `password` 字段类型 → fieldAdapter 透传 → TextField 以 `type="password"` 渲染；`serverSchema` password 字段改用新类型（协议无破坏，向后兼容）。
- **涉及文件**：`CommandInput.vue`、`buildConsole/App.vue`、`SchemaForm.vue`、`useConsolePage.ts`、`formSchema.ts`、`fieldAdapter.ts`、`TextField.vue`、`serverSchema.ts` + 各 spec。
- **验收标准**：每项配组件测试；全量单测绿；e2e（Playwright）可复跑绿。
- **回滚边界**：每项独立；3e 为纯新增枚举值，不改既有字段行为。

### 阶段 4 · 测试补全（覆盖 §4 全部 14 项缺口）

- **涉及文件**：新增 `environmentTreeProvider.spec.ts`、`draftCommands.spec.ts`、`initTreeProvider.spec.ts`、`serverGuard.spec.ts`、`models.spec.ts`、`serialConsoleController.spec.ts`、`buildSchema.spec.ts`、`probes.spec.ts`、`CommandInput.spec.ts`、`ConsoleOutput.spec.ts`、`HistoryPanel.spec.ts`、`VToolbar.spec.ts`、`iconNames.spec.ts`、`pages.spec.ts`、gallery App 冒烟；扩展 `vitest.config.ts`。
- **验收标准**：统计面内全部源文件有直接测试；测试间零相互依赖（自建临时目录/状态，finally 清理）；连续 3 次运行结果稳定一致。
- **回滚边界**：纯增量，不触碰生产代码。

### 阶段 5 · P3 清理（低风险高价值项）

- **5a 死代码删除**：stableStringify（+spec）、clearError、datalist 标记、isIconName（P3-A1~A4；P3-A5 dirty/cancel 协议保留不删，记录为后续接线项）。
- **5b 漂移修正**：P3-B1~B7 注释/文案/命名修正。
- **5c 资源释放**：initTreeProvider、environmentTreeProvider、serialConsoleController 的 emitter/subscription dispose 化；SerialConsolePanel.current 清理（P3-D1~D3、D5；D4 记录为后续项）。
- **5d 小修**：serverGuard baudRate 校验、reasonOf 收敛为共享助手、editSerialServer/connect handler 合并、树视图 load 错误经 onWarning 上报（P3-E1、C1、C3、B7）。
- **明确不做**（记录为后续迭代）：P3-C2 面板单例结构重构（改动面大收益低）、P3-E2 草稿箱防御细节、P3-F 组脚本健壮性（当前无实际故障）、P3-G2/G3、P3-H 组 UX 小项。
- **验收标准**：lint（无新豁免）/ 类型检查 / 全量单测 / e2e 绿；行为与优化前一致。
- **回滚边界**：各小项独立，任何一项 revert 不影响其他。

### 阶段 6 · 收尾与规范固化

- 全量 `npm run gate -- --fast` 验证；`agent.md` 写入「每一次 AI 交互必须执行前后端单元测试，全部通过后才允许提交」的强制协作规范；`CHANGELOG.md` 记 [Unreleased] 段（提交时按规约升版本）。
