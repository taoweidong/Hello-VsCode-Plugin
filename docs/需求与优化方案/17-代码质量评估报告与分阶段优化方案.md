- coverage reporter 缺 `json-summary`，无机器可读产物（本报告覆盖率数据靠解析 HTML 获得）；
- 门禁 10 步 + manifest 静态一致性（命令/视图/图标/CSS 链双向闭合）是同类项目少见的水准；缺口仅：nls 双语键一致性无脚本校验（P3，留档）、vsixIntegrity CRC 校验不在 CI（P3，留档）。

## 6. 安全与性能专项结论（正面确认）

- **XSS 面干净**：全库零 v-html/innerHTML/srcdoc/document.write；动态文本全部 Vue 插值自动转义；webviewHtml.ts escapeHtml 覆盖五字符；CSP `default-src 'none'`、script nonce 每帧重生成、无 unsafe-*；诊断兜底 HTML 零脚本。

- **性能健康**：无裸 fs.watch；探针已并行；轮询有可见性门控；各树单飞防抖。仅 P3-07/08/15 小项。
