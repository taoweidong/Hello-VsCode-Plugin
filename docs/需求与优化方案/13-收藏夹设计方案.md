# 13 · 收藏夹（Favorites）设计方案

> 状态：v3.4.0 已实现（本文为实施时点的设计快照）｜编制：2026-11-08
> 目标：把「任意文件 / 文件夹的路径」存成带别名的收藏，侧边栏一点直达。
> 与既有「任务管理器的任务收藏」（`addTaskToFavorites`，收藏的是 tasks.json 任务）正交。

## 1. 背景与参考

高星开源项目对照（调研于 2026-11-08）：

| 参考项目                                       | 借鉴点                                                    | 不采纳                       |
| ---------------------------------------------- | --------------------------------------------------------- | ---------------------------- |
| Project Manager（alefragnani，~2.7k★）         | 别名必设（默认 basename）+ QuickPick 快速打开（招牌交互） | 项目级粒度；闭源部分不参考   |
| Favorite Files（lxuancheng.favorite-files）    | 文件 + 文件夹混排侧栏、右键重命名 / 移除 / reveal         | 拖拽排序（v1 不做，见 §7）   |
| Bookmarks #142（alefragnani/vscode-bookmarks） | 文件 / 目录级收藏是明确缺口（该插件只做行级书签）         | 行级书签（与本项目定位不同） |

## 2. 目标 / 非目标

**目标（v1）**

- 资源管理器右键文件 / 文件夹（单选 / 多选批量）、编辑器右键 / 标题栏当前文件 → 添加收藏；
- 别名：单个添加时弹输入框（默认 basename，可留空），批量添加用 basename，随时重命名；
- 「收藏夹」侧边栏树视图：单击文件 → 编辑器打开；单击文件夹 → 资源管理器 reveal；
- 右键条目：在资源管理器中显示 / 复制路径 / 重命名别名 / 移除（inline 悬停删除按钮）；
- QuickPick 快速打开（`quickOpenFavorites`，命令面板 + 视图标题栏 ⭐）。

**非目标（v1，留作后续）**

- 拖拽排序 / 分组文件夹 / 置顶（数据含 `addedAt`，升级不破坏格式）；
- 跨设备同步、行级代码书签、工作区外文件监听（移动 / 删除后打开失败走错误提示）。

## 3. 领域模型与存储

```ts
interface FavoriteItem {
  id: string // randomUUID
  name: string // 别名（展示名，可重命名）
  path: string // 工作区内 = POSIX 相对路径；工作区外 = 绝对 fsPath
  isFolder: boolean // 添加时按 workspace.fs.stat 判定
  addedAt: string // ISO
}
```

- 存储：`.vscode/favorites.json`（信封 `{ schemaVersion: 1, items: [] }`，原子写 +
  损坏复制 `.bak` 后按空数据继续——复用 serial-servers 的存储契约与双实现形态：
  无工作区回退 globalState 键 `extStarter.favorites`）；
- 上限 200 条，超出丢最旧；已 gitignore；
- 去重：按解析后的绝对路径判重，重复添加给出提示不入列；
- 兼容：顶层数组手写形态宽容读取，下次保存迁移为信封（同 serial 口径）。

## 4. 路径解析策略

- 添加时：URI 在某工作区文件夹内 → 存 POSIX 相对路径；否则存绝对 fsPath；
- 打开时：相对路径逐个工作区文件夹尝试 `fs.stat` 存在性，命中即用；
  全未命中回退第一个文件夹（多根同相对名冲突取先命中者，v1 已知限制）；
- 打开失败（文件被移走）：`showErrorMessage` 如实呈现，不静默。

## 5. 公开面（新增 7 命令 + 1 视图，合计 6 视图 / 35 命令）

| 命令                            | 标题               | 入口                                                         |
| ------------------------------- | ------------------ | ------------------------------------------------------------ |
| `extStarter.addFavorite`        | 添加到收藏夹       | explorer/context（单选+多选）/ editor/context / editor/title |
| `extStarter.quickOpenFavorites` | 快速打开收藏       | 命令面板 + 收藏夹视图标题栏（⭐）                            |
| `extStarter.openFavorite`       | 打开收藏项         | 树条目单击（TreeItem.command）+ 条目右键                     |
| `extStarter.revealFavorite`     | 在资源管理器中显示 | 条目右键                                                     |
| `extStarter.copyFavoritePath`   | 复制收藏路径       | 条目右键                                                     |
| `extStarter.renameFavorite`     | 重命名收藏别名     | 条目右键                                                     |
| `extStarter.removeFavorite`     | 移除收藏           | 条目右键 + inline 悬停按钮（`close` 图标）                   |

带参命令（open/reveal/copy/rename/remove）无参调用给出可操作提示，不抛错（对齐任务管理器命令壳惯例）。
