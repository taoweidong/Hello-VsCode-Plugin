# 基础系统介绍（第三层 · 系统能力与公开接口）

> 回答一个问题：**基于这个模板做二次开发，我手里有哪些可复用的系统能力和公开接口？**
> 功能怎么用（使用者视角）见 [../功能介绍/](../功能介绍/README.md)；
> 每个功能怎么改（代码级实操）见 [../开发指南/](../开发指南/README.md)；
> 为什么这么设计见 [../设计架构/](../设计架构/README.md)。

## 本层定位

Hello-VsCode-Plugin 不是七个孤立功能的堆砌，而是一个 **VSCode 扩展基座**：
每个演示功能背后都是一套可替换领域模型的通用机制（页面基座、表单基座、任务框架、
命令视图基座、存储体系、质量门禁）。本层把这些**系统能力**与**公开接口**从各功能篇中
提炼出来集中呈现——二次开发前先读这一层，再进第五层抄样板动手。

## 二次开发最小路径（三步）

1. 读 [01-系统能力与扩展点](01-系统能力与扩展点.md) 选定要复用的能力；
2. 到 [开发指南](../开发指南/README.md)「我要做什么」路由表找到对应样板篇，复制-修改；
3. `npm run gate -- --fast` 全绿后，按 [`agent.md`](../../agent.md) 版本号规约升版本并记
   [CHANGELOG](../../CHANGELOG.md)，再提交。

> 强制约定（门禁协议 / 测试协议 / 版本号规约）以根 [`agent.md`](../../agent.md) 为准。
