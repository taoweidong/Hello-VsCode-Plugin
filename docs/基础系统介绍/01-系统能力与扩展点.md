# 01 · 系统能力与扩展点

> 六大系统能力逐一说明：职责边界、代码锚点、**扩展承诺**（做常见扩展最少要碰哪里）、
> 详解链接。本篇是能力地图，不复制实现细节——细节在开发指南对应篇。

## 1. Webview 页面基座

- **职责**：Vue 3 页面的注册、构建、加载与生命周期全托管。
- **机制**：`src/webview/pages.ts` 的 `WEBVIEW_PAGES` 是唯一注册表（当前
  gallery / taskManager 两页）→ Vite 多入口构建产出
  `.vite/manifest.json` → 宿主 `assetResolver` 反查入口 chunk 并递归收集 CSS →
  `webviewHtml` 拼 CSP 外壳（nonce、无 `unsafe-*`）→ `WebviewController` 管单例、
  提交幂等与窗口重载恢复（serializer）。
- **扩展承诺**：**新增页面只碰两个文件**——`apps/` 建目录（`main.ts` + `App.vue`）、
  注册表加一行；Vite 入口、资源解析、e2e harness、面板控制器全部自动跟随。
- **锚点**：`src/webview/pages.ts`、`src/webview/host/`。
- **详解**：[开发指南 06 · Webview 页面与表单基座](../开发指南/06-Webview页面与表单基座.md)。

## 2. SchemaForm 表单基座

- **职责**：领域字段表驱动的表单渲染、校验、错误定位与回填。
- **机制**：领域声明 `SchemaFieldDef[]` → `deriveFormSchema` 派生 → `toFieldDefs`
  组装 init 载荷 → `SchemaForm` 按 `field.type` 分发到五类字段组件
  （text / textarea / select / tags / boolean），字段统一包 `VFormField` 语义容器；
  键盘 `Esc` 取消、`Ctrl+Enter` 提交，主按钮先过本地必填校验再发宿主。
- **扩展承诺**：**加一个表单字段只改一处**（领域字段表加一行）；任务管理页面即现成样板。
- **锚点**：`src/webview/components/SchemaForm.vue`、`src/webview/formSchema.ts`、
  `src/extension/features/taskManager/taskSchema.ts`（领域样板）。
- **详解**：[开发指南 06](../开发指南/06-Webview页面与表单基座.md)、
  [开发指南 05 · 草稿箱与右键菜单](../开发指南/05-草稿箱与右键菜单.md)。

## 3. 启动任务框架

- **职责**：窗口加载完成自动执行初始化脚本与环境探针，全生命周期托管。
- **机制**：`StartupTask` 注册表（`TASKS` 数组）+ 可插拔探针注册表
  （`ENVIRONMENT_PROBES`）→ `TaskRunner` 顺序调度：逐任务事件通知、超时裁决、
  异常降级为 error 结果不阻断后续；结果进输出通道并驱动「环境信息 / 环境初始化」
  两个树视图。环境初始化另有步骤注册表（单步重跑、与 runAll 互斥）。
- **扩展承诺**：**加启动脚本/探针只加一条数据**——实现接口后入数组，调度、超时、
  打印、视图分组零改动。
- **锚点**：`src/extension/tasks/taskRegistry.ts`、`probes.ts`、`taskRunner.ts`、
  `src/extension/features/init/initSteps.ts`。
- **详解**：[开发指南 01 · 启动任务与环境探针](../开发指南/01-启动任务与环境探针.md)、
  [开发指南 02 · 环境初始化](../开发指南/02-环境初始化.md)。

## 4. 命令与视图基座

- **职责**：命令 / 视图 / 配置 / 菜单 / 文案的声明式装配与一致性守护。
- **机制**：ID 只在 `src/extension/constants.ts` 的 `COMMAND` / `VIEW` / `CONFIG`
  定义；`package.json` contributes 用 `%key%` 占位符走 `package.nls*.json` 双语文案；
  命令实现按场景分组在 `src/extension/commands/`；门禁第 ⑥ 步静态校验
  「清单 ↔ 常量 ↔ 注册」三方闭合，漏一处立刻红。
- **扩展承诺**：新增命令三步（constants → contributes+nls → commands 分组注册），
  有门禁兜底不漏步。
- **锚点**：`src/extension/constants.ts`、`src/extension/commands/`、
  `package.nls.json` / `package.nls.zh-cn.json`。
- **详解**：[开发指南 07 · 命令视图与 i18n](../开发指南/07-命令视图与i18n.md)；
  公开面全量清单见 [02-公开接口总表](02-公开接口总表.md)。

## 5. 存储与安全体系

- **职责**：数据落盘、双实现回退与凭据安全。
- **机制**：工作区数据文件走共享信封存储（`jsonEnvelopeStore`：BOM/顶层宽容/
  损坏复制 `.corrupt-*.bak` 备份 + `atomicWrite` 原子写）；写路径经
  `queuedFileStore` 串行化「加载先行 + 写前重读」，多窗口不互相覆盖；
  未打开工作区时回退 globalStorage 明文 JSON（收藏夹 / 快捷命令）；
  工作区数据文件一律 `.vscode/*.json` 且必须同步 `.gitignore`。
- **扩展承诺**：新增落盘领域 = 复用 `JsonEnvelopeFileStore` + 注册一个解析回调
  - `.gitignore` 加一行；敏感字段参照「数据文件零明文」口径（v4.0.0 起无串口
    密码存储，通用凭据方案见 agent.md 硬性规约）。
- **锚点**：`src/extension/services/stores/atomicWrite.ts`、
  `src/extension/services/stores/jsonEnvelopeStore.ts`、
  `src/extension/services/stores/queuedFileStore.ts`、
  `src/extension/features/drafts/draftBoxService.ts`。
- **详解**：[开发指南 11 · 收藏夹](../开发指南/11-收藏夹.md)、
  [开发指南 05 · 草稿箱与右键菜单](../开发指南/05-草稿箱与右键菜单.md)。

## 6. 质量门禁与测试体系

- **职责**：改完代码到「可交付」的机械化守护。
- **机制**：三层测试——单测（Vitest + jsdom + vscode 桩，覆盖率阈值约束，秒级反馈）、
  宿主集成（@vscode/test-electron 真实宿主）、e2e（Playwright 真实浏览器，
  `--with-e2e` 进门禁）；一键门禁 10 步：lint/格式 → 类型 → 宿主构建 → Webview 构建 →
  测试编译 → 静态一致性 + 样式门禁（令牌强制 / CSP 红线 / 清单闭合）→ 单测 →
  集成 → vsce 黑白名单 + bundle 预算 → e2e（可选）。
- **扩展承诺**：任何改动收尾前 `npm run gate` 必须全绿——写测试的位置、覆盖率口径、
  常见坑都在详解篇。
- **锚点**：`scripts/gate.ts`、`scripts/checks/`、`src/test/unit/stubs/vscode.ts`。
- **详解**：[开发指南 08 · 测试门禁与打包](../开发指南/08-测试门禁与打包.md)。

## 7. VSCode 原生设计系统（横切）

- **职责**：全部 Webview 界面的视觉与交互基线——「像 VSCode 团队自己出品的一样」。
- **机制**：语义令牌唯一来源 `src/webview/ui/tokens.css`（组件只消费 `--ui-*`，
  令牌映射 `--vscode-*` 主题变量）；12 个自研基础组件（`V*` 系列 11 个 + `AppShell`）；
  尺寸/颜色/静态 style 由样式门禁强制；画廊页是活的设计系统验收基准。
- **扩展承诺**：新界面直接抄 `apps/gallery/` 的组件用法，视觉合规由门禁兜底。
- **锚点**：`src/webview/ui/`、`src/webview/apps/gallery/`。
- **详解**：[设计架构 02 · 设计决策索引](../设计架构/02-设计决策索引.md)、
  [需求与优化方案 04 · VSCode 原生设计系统](../需求与优化方案/04-VSCode原生设计系统.md)。
