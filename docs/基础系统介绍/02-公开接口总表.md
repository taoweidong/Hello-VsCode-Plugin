## 3. 配置项（9 项，`extStarter.*`）

| 设置项                    | 默认   | 说明                                                      |
| ------------------------- | ------ | --------------------------------------------------------- |
| `runStartupTasks`         | 开启   | 激活时自动执行启动任务（初始化脚本 + 环境检测）           |
| `serialConsoleEnabled`    | 开启   | 串口控制台功能开关                                        |
| `taskApiBaseUrl`          | 留空   | 任务管理 HTTP 基地址；留空 = 打桩模拟（修改后需重载窗口） |
| `taskGroupWithSeparator`  | 开启   | 任务 label 按分隔符拆入虚拟文件夹分组                     |
| `taskGroupSeparator`      | `-`    | 任务分组分隔符（支持多字符）                              |
| `taskGroupMaxLevel`       | 5      | 分组拆层深度上限（1-15）                                  |
| `taskGroupStripTaskLabel` | 开启   | 叶子任务剥掉分组前缀只显示剩余段                          |
| `taskNumLastTasks`        | 10     | 「最近运行」展示条数（1-20，存储上限恒 20）               |
| `taskExpanded`            | 全展开 | 最近运行 / 收藏分组的默认展开状态（object）               |

## 5. 宿主 ↔ 页面协议（21 消息，唯一契约 `src/webview/protocol.ts`）

**宿主 → 页面（9）**：`init`（schema + 领域载荷）、`submitAck`（提交受理成功）、
`error`（错误 + 可选 field 定位）、`serialPorts`、`serialServers`、`serialState`、
`serialData`、`commandHistory`、`taskList`（分页页）。

**页面 → 宿主（12）**：`ready`、`submit`（新建/编辑统一提交，`draft.id` 区分）、
`serialPortsRequest`、`serialServerSave`、`serialServerDelete`、`serialConnect`、
`serialDisconnect`、`serialSend`、`commandHistoryRemove`、`commandHistoryClear`、
`taskListRequest`、`taskDelete`。

> 两侧收发前必须过运行时守卫 `isHostMessage` / `isWebviewMessage`；
> 加消息的完整步骤见 [开发指南 06 · 加一条消息](../开发指南/06-Webview页面与表单基座.md)。

## 6. HTTP 契约（任务管理真实接口，`extStarter.taskApiBaseUrl`）

| 操作        | 方法与路径                                               |
| ----------- | -------------------------------------------------------- |
| 查询 / 分页 | `GET /tasks?keyword=&status=&buildType=&page=&pageSize=` |
| 新建        | `POST /tasks`                                            |
| 编辑        | `PUT /tasks/:id`                                         |
| 删除        | `DELETE /tasks/:id`                                      |

服务端契约类型（`TaskItem` / `TaskQuery` / `TaskPage` / `TaskCreatePayload` /
`TaskUpdatePayload`）见 `src/extension/features/taskManager/taskApiClient.ts`；
对接实操见 [开发指南 03 · 任务管理](../开发指南/03-任务管理.md)。
