# 10 · 端到端实战教程：新增一个完整领域

> 把五大基座串起来走一遍：以新增「**网页速记（webNotes）**」领域（示例名，仓库中不存在）
> 为线索，从 ID 到页面到测试交作业的完整路线图。每步只给「抄哪个样板、门禁兜什么、
> 详见哪篇」——步骤里的机制细节以链接篇为准，本篇不复制。
>
> 适用前提：已跑通 [操作指导 01/02](../操作指导/README.md)（`npm install`、F5 可调试），
> 读过 [agent.md](../../agent.md) 强制约定与 [01 · 系统能力与扩展点](../基础系统介绍/01-系统能力与扩展点.md)。

## 路线总览

```text
①定 ID → ②领域字段表 → ③存储 → ④树视图 → ⑤命令/菜单 → ⑥注册页面
→ ⑦协议消息 → ⑧宿主面板 → ⑨页面 App → ⑩测试 → ⑪门禁交作业
```

## ① 定 ID（单一来源）

- 命令/视图/配置 ID 加进 `src/extension/constants.ts` 的 `COMMAND` / `VIEW` / `CONFIG`；
- 门禁第 ⑥ 步校验「清单 ↔ 常量 ↔ 注册」三方闭合——先定 ID，后面漏声明立刻红。
- 详见 [07 · 命令视图与 i18n](07-命令视图与i18n.md)。

## ② 领域字段表（表单基座）

- 新建 `src/extension/features/webNotes/webNoteSchema.ts`，抄
  `features/taskManager/taskSchema.ts`：声明 `BOOKMARK_FIELD_DEFS`
  （如 title=text 必填、url=text 必填、tags=tags 选填、notes=textarea 选填）；
- 「加字段只改一处」由 SchemaForm 兑现：渲染/校验/错误定位/默认值全自动。
- 详见 [06 · Webview 页面与表单基座](06-Webview页面与表单基座.md)。

## ③ 存储（原子写 + 双实现 + 守卫）

- 新建 `webNoteStore.ts`，复用 `services/stores/jsonEnvelopeStore`（原子写 +
  损坏 `.corrupt-*.bak` 备份 + 顶层宽容读取），写路径经 `queuedFileStore`
  串行化（写前重读）；无工作区回退 globalStorage 明文 JSON（抄
  `features/favorites/favoritesService.ts` 的装配与迁移口径）；
- **`.gitignore` 同步加一行**（铁律 3，漏了会在协作仓库产生脏文件）。
- 详见 [11 · 收藏夹](11-收藏夹.md)（信封存储与迁移详解）。

## ④ 树视图

- 新建 `webNoteTreeProvider.ts`，抄 `features/taskManager/taskManagerTreeProvider.ts`：
  `getChildren` 投影 store 数据、`onDidChangeTreeData` 触发刷新、
  `TreeItem.command` 决定单击行为；
- `package.json` contributes.views 加视图声明（文案走 nls）。
- 详见 [09 · 任务管理器](09-任务管理器.md)。

## ⑤ 命令与菜单

- `commands/` 对应分组 `register(COMMAND.*, ...)`；`package.json` contributes.commands
  - menus（编辑器/资源管理器右键按需）+ 两份 nls 文案；
- 常见坑：`view/item/context` 第一个参数是树节点，需 `toItem()` 归一化。
- 详见 [05 · 草稿箱与右键菜单](05-草稿箱与右键菜单.md)、[07](07-命令视图与i18n.md)。

## ⑥ 注册页面（两个文件）

- `src/webview/pages.ts` 的 `WEBVIEW_PAGES` 加一行
  `{ id: 'webNotes', title: '网页速记', entry: 'src/webview/apps/webNotes/main.ts' }`；
- 复制 `src/webview/apps/gallery/` → `apps/webNotes/`（`main.ts` + `App.vue`）；
- Vite 入口 / manifest / e2e harness / serializer 自动跟随。
- 详见 [06](06-Webview页面与表单基座.md)。

## ⑦ 协议消息

- `protocol.ts` 加联合类型分支（如 `webNoteList` / `webNoteSave` / `webNoteDelete`）
  - 对应运行时守卫 case（逐字段窄化，禁止 any 直收）；Wire 类型字段最小化；
- 加消息三处同步：协议 ↔ 宿主分发 ↔ 页面监听（先过 `isHostMessage`）。
- 详见 [06 · 加一条消息](06-Webview页面与表单基座.md)。

## ⑧ 宿主面板

- 新建 `webNotePanel.ts`，抄 `features/taskManager/taskManagerPanel.ts`：
  经 `WebviewController.createOrShow('webNotes', context, deps)` 打开，deps 按需给——
  `buildInit`（schema = 字段表派生 + 初值 + extra 列表数据）、`onSubmit`（保存，抛错时
  给 err 附 `field` 定位控件）、`onPageMessage`（处理 ⑦ 的页面消息）、`onDispose`（释放资源）；
- 提交幂等 / 10s 超时 / serializer 恢复全部由控制器托管，不要自己重造。
- 详见 [设计架构 03 · 关键流程与协议时序](../设计架构/03-关键流程与协议时序.md)。

## ⑨ 页面 App.vue

- 结构参考 `apps/taskManager/App.vue`：`ready` → 收 `init`（`toFormFields` 适配字段表）
  → SchemaForm 表单 + 列表区 → 操作 `post` 消息 → 收宿主应答刷新；
- 草稿/选中态用 `api.setState` 自持久化（重载后从 `init.extra.persisted` 恢复）；
- 危险操作（删除）用 `useTwoStepConfirm` 两段式布防，**禁止浏览器 confirm**（门禁规则 8）；
- 样式只用 `--ui-*` 令牌，新规格先登记 tokens.css（样式门禁强制）。
- 详见 [06](06-Webview页面与表单基座.md)、[设计系统 04](../需求与优化方案/04-VSCode原生设计系统.md)。

## ⑩ 测试（三层各就各位）

| 层   | 放哪                                        | 抄哪个                                            |
| ---- | ------------------------------------------- | ------------------------------------------------- |
| 单测 | `src/test/unit/webNotes/*.spec.ts`          | `taskManager/` 各 spec（store/schema/panel/tree） |
| 组件 | `src/test/unit/webview/webNotesApp.spec.ts` | `taskManagerApp.spec.ts`（消息流驱动断言）        |
| e2e  | `tests/e2e/webNotes.spec.ts`                | `taskManager.spec.ts`（harness 自动纳入新页面）   |

- 惯用法：`__resetStubs()` 清副作用、`__setConfig(...)` 造配置、`__stubs.outputLines`
  断言输出通道——桩只增不减；
- 覆盖率有整体与分目录阈值，删代码比补测试更容易破阈值。
- 详见 [08 · 测试门禁与打包](08-测试门禁与打包.md)。
