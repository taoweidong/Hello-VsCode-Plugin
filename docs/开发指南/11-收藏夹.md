> v3.4 新增（13 方案）：文件 / 文件夹路径收藏 + 别名 + 单击跳转。它是「**双实现存储 +

> 侧边栏展示、点击有动作」的领域，从这篇出发。

## 核心机制

```text
右键/标题栏 addFavorite(uri[, uris[]])
  → 单条弹 showInputBox 别名（默认 basename）；批量静默用 basename
  → FavoritesService.add：workspace.fs.stat 判文件夹 → 相对化（POSIX）→
     去重（解析后同路径跳过）→ 插头部（批量保持选择顺序）→ 原子落盘
  → onDidChange → 树视图刷新
条目单击 openFavorite → resolveFavoriteUri（相对路径逐工作区文件夹 stat 命中）
  → 文件 executeCommand('vscode.open') / 文件夹 executeCommand('revealInExplorer')
存储：.vscode/favorites.json 信封 { schemaVersion, items } + 原子写 + 损坏 .bak 备份；
      无工作区落 globalStorage 明文 favorites.json（GlobalJsonFavoritesStore，v3.6/15 方案——
      可手动拷贝迁移；旧 globalState 数据由 migrateFavoritesMementoToFile 激活期一次性迁移）；
      上限 200 丢最旧
```

- **存储契约**与 serial-servers 同口径（信封 / 顶层数组宽容读取 / 损坏备份后按空继续），
  差异只在领域字段与守卫规则——换领域 = 换字段表 + 守卫，存储骨架照抄；
- **路径策略**：工作区内存 POSIX 相对路径（仓库可迁移），打开时逐文件夹解析存在性，
  全未命中回退第一个文件夹（多根同名限制见设计方案 §4）；
- 移除无确认（低危、可重加）；重命名走 `showInputBox` 预填。

## 扩展实操

### A. 换一个「收藏什么」

字段在 `FavoriteItem`：加字段（如备注 `note`）= 接口 + `normalizeFavoriteItem` 守卫 +
树 tooltip 三处同步；老数据文件缺字段由守卫兜底补默认值，无需迁移脚本。

### B. 加一个条目动作（如「在新窗口打开文件夹」）

1. `constants.ts` 的 `COMMAND` 加 ID；2. `package.json` contributes.commands +
   `view/item/context` 菜单（`viewItem == favorite`）+ 两份 nls；3. 命令壳薄委托
   `FavoritesService` 新方法；门禁第 ⑥ 步校验三方闭合。

### C. 改排序 / 加分组

`FavoritesService.list()` 是唯一数据出口——排序在返回前做（如按 `name`）；
分组树参考 [09 · 任务管理器](09-任务管理器.md) 的多级 `getChildren` 形态。

## 常见坑

- 单测里 `vscode.workspace.getWorkspaceFolder` 由测试桩提供（按路径前缀匹配，
  v3.4 增量扩展）；服务自身不依赖它也可运行（无工作区回退绝对路径）；
- 批量添加保持**选择顺序**插头部——不要逐条 `unshift`（会整体反序，第一轮实现踩过）；
- 条目对象经 `TreeItem.command.arguments` 原样回传命令壳，命令壳用结构化守卫
  （`isFavoriteItem`）校验而非盲转——带参命令无参调用一律给提示不抛错。
