## 核心机制

```text
Ctrl+Alt+K toggleBookmark（when: editorTextFocus）
  → 守卫：无活动编辑器 / 非 file: 协议 → information 提示，不产生数据
  → BookmarksService.toggle(uri, line, document.lineAt(line).text)：
     同 toPosix(path)+line 已存在 → 移除；否则插头部（文本快照 trim/100 截断/空行占位）
     → 上限 500 丢最旧 → 原子落盘 → onDidChange → 树刷新
jumpToNext/PreviousBookmark
  → 空列表 → 「暂无书签：在编辑器中按 Ctrl+Alt+K 给当前行添加书签」
  → service.next(uri|undefined, line|undefined, direction)：排序键 (toPosix(path), line) 升序；
     当前位置按打书签同款规则归一化成同序键；next=严格晚于的第一条（尾后回绕到首）、
     prev=严格早于的（首前回绕到尾）；无编辑器兜底 next=首条 / prev=末条；
     路径比较用普通字符串序（不用 localeCompare，跨环境确定）
  → service.jump(target)：resolveBookmarkUri（与收藏夹 resolveFavoriteUri 同语义）→
     openTextDocument → showTextDocument → selection 行首 + reveal 居中（视口外才居中）；
     行号越界钳制到最后一行并如实提示
存储：.vscode/bookmarks.json 信封 + 原子写 + 损坏 .bak（与收藏夹完全同契约）；
      无工作区落 globalStorage 明文 bookmarks.json（15 方案口径）；上限 500 丢最旧
```

- **keybindings 贡献**（`package.json` 顶层 `keybindings` 数组）：
  三条均带 `"when": "editorTextFocus"`（反目标：编辑器未聚焦绝不触发）；
  `"mac"` 字段换 Cmd 变体；键位对齐 Bookmarks 原版默认（同装冲突可重绑）。
  门禁第 ⑥ 步会闭合校验 keybindings 引用的命令（三处缺一不可）。
- **0-based 口径**：`BookmarkItem.line` 存 0-based（VSCode API 口径），
  一切展示（树 description `L{n+1}` / QuickPick label / 提示文案）统一 +1。
- **树单击路由**：TreeItem.command 指向带参命令 `jumpToBookmark`（镜像收藏夹
  `openFavorite` 模式）——树条目不能直接执行服务方法，必须经命令中转。

## 扩展实操

### A. 加一个「书签动作」（如「复制书签路径与行号」）

1. `constants.ts` 的 `COMMAND` 加 id → `bookmarksCommands.ts` 注册薄壳（带参命令
   无参调用给提示）→ `package.json` commands + menus（`viewItem == bookmark` 组）+
   nls 双语 → 门禁闭合；
2. 服务层加方法（如 `copyTarget(item): Promise<string>`）+ 单测。

### B. 给书签加 gutter 图标（升级方向）

装饰器（`vscode.window.createTextEditorDecorationType`）+ 文件打开时的对账渲染，
数据模型无需变更（`BookmarkItem` 已留字段余量）——见设计方案 §2 非目标，
实现时注意行号漂移对账口径（v1 无编辑追踪，装饰与跳转同源即不会误导）。

### C. 换循环导航排序

改 `BookmarksService.ordered()` 一处即可（`next()`/树分组都吃它的输出）——
如改为「按打点时间倒序」，同步调整树分组保序逻辑与单测 ⑫⑬⑭。

## 常见坑

- **行号是 0-based**：服务与存储全 0-based，展示层统一 +1——混用必错；
- **循环导航的「当前位置」归一化**：必须与打书签同款规则（工作区内相对 POSIX、
  否则绝对 fsPath），再构造 `(toPosix(path), line)` 同序键——直接拿绝对路径比
  相对存储路径会永远比不中；
- **测试里的 `Uri.parse`**：测试桩把一切 URI 归一为 `file:` 协议——要测非 file
  守卫，注入带 `scheme` 字段的形状对象（见 bookmarksCommands.spec ③）；
- **keybindings 三处闭合**：`package.json` keybindings 引用的命令必须在 commands
  与 constants 同时存在，否则门禁第 ⑥ 步红。
